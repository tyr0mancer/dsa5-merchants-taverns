# dsa5-merchants-taverns
DSA5 NPC Character Sheet zum Handel. 
- Kann Warenverfügbarkeit nach Rolltables oder aus der DSA5 Bibliothek auswürfeln. 
- Unterstützt das [DSA5 Traveller Modul](https://github.com/tyr0mancer/dsa5-traveller)
- Bietet (noch) keinen automatisierten Warentransfer, lediglich drag-drop aus Chat Message.
